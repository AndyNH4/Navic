# Rezeener 歌词格式标准

适用于：music-tag-web 编辑 → Navidrome 服务 → Rezeener 客户端。
所有格式都经实测验证可完整穿过该链路（Navidrome 原样透传行内标签，客户端解析）。

## 1. 基础：行级同步歌词（标准 LRC）

每行行首一个时间戳 `[mm:ss.xxx]`（毫秒或百分秒均可）：

```lrc
[ti:Angel]
[ar:陶喆]
[al:黑色柳丁]

[00:25.960]镜子中 看见一张陌生的脸
[00:32.100]那眼神 如此黯淡
```

- 没有时间戳的行按静态歌词显示
- 客户端支持自动滚动、点击跳播

## 2. 逐字歌词（karaoke）

在行级时间戳之后，**每个字/词前加内联时间戳**，两种格式都支持（可混用，推荐用哪种都行）：

- 方括号：`[mm:ss.mmm]`（music-tag-web 友好，兼容所有 Navidrome 版本）
- 尖括号：`<mm:ss.xx>`（标准 ELRC，Navidrome 0.63+ 官方通道也认）

```lrc
[00:25.960]镜[00:26.170]子[00:26.420]中 [00:27.880]看[00:28.050]见[00:28.240]一[00:28.500]张[00:28.810]陌[00:29.170]生[00:29.430]的[00:29.800]脸[00:30.370]
```

效果：当前正在唱的字**放大 + 加粗**，歌词按字擦除推进。

规则：
- 行内第一个标签是整行开始时间，后续每个标签对应它后面的那个字/词
- 空格、标点也可以有自己的时间戳（不影响显示）
- 没有任何逐字标签的行 → 自动回退为整行匀速渐变（客户端里叫「假逐字」，可在设置中关闭）
- 设置开关：设置 → 播放（Now Playing）→ 歌词组 →「逐字放大」，默认开启；对不支持的歌曲自动回退行级显示

## 3. 双语歌词（自定义 `[tr]` tag 约定）

翻译行 = 与原文**相同的时间戳** + 文本以 `[tr]` 开头：

```lrc
[ti:Angel]
[ar:陶喆]
[al:黑色柳丁]
[tr-lang:en]                                    ← 可选：声明翻译语言

[00:25.960]镜子中 看见一张陌生的脸
[00:25.960][tr]In the mirror, a stranger's face
[00:32.100]那眼神 如此黯淡
[00:32.100][tr]That gaze, so dim
```

规则：
- `[tr]` 行与它**同时间戳**的非 `[tr]` 行配对（与书写顺序无关，客户端按时间戳分组配对）
- 孤立的 `[tr]` 行（找不到同时间戳原文）按普通行显示，不会丢
- 文件头 `[tr-lang:xx]` 可选：语言代码（如 en、ja、zh-Hant）或任意短文本，会显示在翻译按钮上；不写则按钮显示「译」
- 翻译行**不要**写逐字标签（翻译只做行级显示）
- 检测到翻译的歌曲：歌词页右下角出现浮动翻译按钮，点击切换双语显示；选择全局记住

## 4. 完整示例（逐字 + 双语）

```lrc
[ti:Angel]
[ar:陶喆]
[al:黑色柳丁]
[tr-lang:en]
[offset:0]

[00:25.960]镜[00:26.170]子[00:26.420]中 [00:27.880]看[00:28.050]见[00:28.240]一[00:28.500]张[00:28.810]陌[00:29.170]生[00:29.430]的[00:29.800]脸[00:30.370]
[00:25.960][tr]In the mirror, a stranger's face
[00:32.100]那[00:32.310]眼[00:32.530]神[00:33.570]如[00:33.830]此[00:34.120]黯[00:34.390]淡[00:35.430]
[00:32.100][tr]That gaze, so dim
```

## 注意事项

- Navidrome 会把行内 `[...]` 标签原样传给客户端，不要在行文本里写不想显示的方括号内容
- 客户端按时间戳配对翻译行，同一时间点最多一条原文 + 一条翻译
- 多段重复副歌如需翻译，每个时间戳都要写对应 `[tr]` 行
- 旧的纯逐字文件（无 `[tr]`）行为不变：双语按钮不出现
